# 図面差分・枠基準補正ツール

PDF または TIF/TIFF の旧図面・新図面を画像化して比較し、変更箇所を色分け表示する Python デスクトップアプリです。

## 主な機能

- PDF（PyMuPDF）と TIF/TIFF（Pillow）の単ページ・複数ページ読み込み
- OpenCV によるグレースケール化、二値化、ノイズ除去、線抽出
- 図面外周に近い大きな矩形枠の自動検出（上位候補を表示）
- 枠候補クリック選択、または四隅クリックによる手動枠指定
- 新図面を旧図面の枠に合わせる平行移動・倍率・微小回転補正
- 差分色分け表示
  - 共通線: 黒
  - 旧図面のみ: 青
  - 新図面のみ: 赤
  - 背景: 白
- 青・赤の差分領域をクラスタ化し、変更箇所矩形と番号を生成
- PNG / PDF / CSV / JSON 出力
- 拡大、縮小、パン対応ビューア

## セットアップ

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

Linux/macOS の場合は以下です。

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

## 起動方法

Windows:

```bat
run.bat
```

共通:

```bash
python -m drawing_diff_tool.main
```

## 操作説明

1. **旧図面を選択** ボタンで旧 PDF/TIF を読み込みます。
2. **新図面を選択** ボタンで新 PDF/TIF を読み込みます。
3. ページ番号と DPI を確認します。複数ページの場合は比較したいページを選択します。
4. 必要に応じて二値化方式、線幅許容、ノイズ除去面積、変更箇所結合距離、変更範囲余白を調整します。
5. **外枠自動検出** を押し、旧図面・新図面に表示された候補枠をクリックして基準枠を選択します。
6. 枠が検出できない場合は **旧枠を手動四隅指定** または **新枠を手動四隅指定** を押し、対応するビューで枠の四隅をクリックします。
7. **補正プレビュー** で、新図面が旧図面の枠に合うよう補正されたことを重ね合わせビューで確認します。
8. **差分実行** を押すと、共通線は黒、旧図面のみは青、新図面のみは赤で差分結果が表示されます。
9. **PNG出力**、**PDF出力**、**CSV出力**、**JSON出力** で結果を保存します。

## テストデータ生成

```bash
python scripts/generate_test_data.py test_data
```

生成される主なケース:

- 同一図面
- 新図面に線を追加
- 旧図面から線を削除
- 線の位置を移動
- 新図面全体を 2mm 相当（400dpi で約 31px）平行移動
- 新図面全体を 0.2% 拡大
- 新図面全体を 0.2 度回転
- 外枠が複数ある図面
- ノイズがある図面

## 既知の制約事項

- PDF はベクター差分ではなく、指定 DPI でラスタライズした画像差分として比較します。
- 初期実装ではページペアは同じページ番号同士です。任意ページ同士の詳細ペア編集は今後の拡張対象です。
- UI からは相似変換（平行移動・倍率・回転）を使用します。射影変換の処理関数は用意していますが、UI 上の既定操作は MVP 要件に合わせて相似変換です。
- 大判・高 DPI の複数ページ PDF はメモリ使用量が大きくなるため、プレビュー DPI を下げてから確認することを推奨します。
- スキャン品質が悪い図面では、局所しきい値やノイズ除去面積を調整してください。
